# Sources and cited claims

The bibliography for *Joint Safe-Region and Path Planning for Durable API Rollouts* is maintained in `../paper/bibliography.json` and generated into
`../paper/references.bib`.

| File | Content |
| --- | --- |
| [reference_audit.csv](reference_audit.csv) | Ordered references, argument roles and citation counts |
| [reference_sources.csv](reference_sources.csv) | Sources used and the scope of each review |
| [docs/claim-source-audit.csv](docs/claim-source-audit.csv) | Manuscript claims, source locations and reading depth |

The reading records distinguish relevant body passages, abstracts or opening
summaries, official policies and publisher previews. A claim is limited to the
material actually reviewed. The bibliography checker verifies consistency among
the manuscript, metadata and citation inventory.

The closest comparisons concern local invariant-preserving conditions,
segmented execution, distributed upgrade scheduling and maximal safe products.
Published upgrade policies define the numerical constraints used in the policy
cohorts. The paper distinguishes these input declarations from application
behavior and from the execution guarantees of the durable protocol.
