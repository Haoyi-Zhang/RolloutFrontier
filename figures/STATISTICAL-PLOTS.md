# Statistical plots and their data

The [manuscript figure map](../../paper/figures/README.md) identifies the figures
used in the main article and supplement. The compiled
[figure atlas](../../paper/figure_atlas.pdf) shows their actual numbering,
placements and grayscale inspection copies.

| Scientific comparison | Python generator under `paper/` | Retained inputs under `artifact/results/` |
| --- | --- | --- |
| Factored planning CPU cost and peak memory through 1,024 owners | `draw_factored_scale.py` | `factored-scale/summary.json`, both checked summaries and the 50 fresh-worker records |
| Earlier matched-goal planning CPU cost | `draw_extensions.py` | `structured-planning/timing-summary.json` and all worker records |
| Owner communication for identical installation paths | `draw_phase_communication.py` | `phase-granularity/` paired process traces and summaries |
| Cumulative static-batch planning cost | `draw_direct_reuse.py` | `direct-optimization/` complete repetitions |

The factored scale plot reports medians and full ranges across five worker
mean CPU costs and five process peak-memory observations per condition. Repeated
cold CPU cohorts within a worker are aggregated before that comparison. Its owner axis describes planner input size, while the physical
execution campaign separately uses up to 32 owner processes on one host.

The mechanism figure `factored-contracts.pdf`, generated by `draw_factored.py`,
uses the actual schema probes, the complete enum-alias query stream and the
recognition certificate for directed cycle graph 25 in `schema-census/`. Its
three-phase joint plan and four-phase priority path come from the retained
witnesses. The four wire mechanisms and their two distinct matrix shapes remain
separate from the number of graph instances.

Run `sh paper/build.sh` from the project root with the publication dependencies
listed in [paper/README.md](../../paper/README.md). It regenerates the statistical
figures from retained observations and compiles the manuscripts. Run
`python -B paper/build_figure_atlas.py` afterward to regenerate the atlas from the
newly compiled placements.

## Auxiliary plotting diagnostics

The build also runs `paper/prepare_evidence.py`, `artifact/export_figures.py`
and `paper/figures/draw_statistical.py` to maintain two auxiliary exports:

- `paper/figures/changes-python.pdf` uses `results/network.csv`. It sums installed
  changes across six seeds in each development family for the fixed-branch,
  greedy-envelope and exact-frontier policies. Separate vertical positions keep
  equal counts visible without changing their horizontal values.
- `paper/figures/corners-python.pdf` uses `results/costs.json`. It converts
  five-repeat checker medians from nanoseconds to milliseconds and compares
  safe products with products whose final corner is unsafe on a logarithmic
  time axis. These measurements concern the checker alone.

These exports support the publication-build regression checks for data-driven
rendering, missing dependencies and deterministic output. They carry no figure
numbers in the article or supplement. Regeneration reads the recorded data;
it does not rerun the timed experiments.
