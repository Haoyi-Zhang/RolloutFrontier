# Earlier input-validation captures

These complete captures precede the strict UTF-8 input-domain check. Their
executed sources, measurements, raw operations, database snapshots and prior
delivery acceptance records are retained unchanged. The input-validation
defect concerns malformed strings that never belonged to the Protobuf string
domain; these earlier application corpora contain valid Unicode inputs.

The current result directories contain fresh executions of the corrected
implementation. Publication values use those current captures. Earlier and
current timing observations are not pooled. `retention.json` binds every
preserved file to its original bytes.

The four earlier application checker aggregates are retained here with the
captures they checked. Current application checks reside inside their
respective current result directories and supply the publication build.
